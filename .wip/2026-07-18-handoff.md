## ⚠ 最初に読む — Unity MCP の接続は「1席」しかない

Unity MCP は **direct 接続を同時に1本しか許さない**(Project Settings > AI > Unity MCP に "1 direct connection allowed at a time")。**Claude Desktop がMCPで繋ぐと、Claude Code の接続を弾く(逆も同様)。**

- 症状: ツール呼び出しが `{"error": "Connection revoked. ..."}` を返し続ける。Accept やブリッジ再起動では直らないことがある。
- 真因: `relay_win.exe --mcp`(親=`claude`)のクライアント側リレーが複数生き残り、1つの席を奪い合う。Unityコンソールに `Connection denied: previously rejected by user`(Bridge.cs:1245)。
- 修復: クライアント側リレー(`relay_win.exe` で**親が Unity でないもの**)を**全部** kill する。Unity 自身のブリッジ(親=`Unity`)は残す。その後ツールを叩けば1本だけ張り直り、空席に入る。
- **Desktop への依頼**: このリポジトリで Unity を触る作業は原則 Claude Code(44)が担当する。Desktop 側で Unity MCP を掴んだままにしないこと。使い終えたら接続を切る。
