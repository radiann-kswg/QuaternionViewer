## 1. 目的

クォータニオンによる回転姿勢の表現を、**地球儀のように直感的・視覚的に確認できる**Unityシーンを構築する。

到達目標は、以下を「式ではなく画面で」示すこと。

1. 四元数の4成分が、回転軸 $\mathbf{n}$ と回転角 $\theta$ に**分解して読める**こと
2. なぜ**半角** $\theta/2$ が現れるのか
3. $q$ と $-q$ が**同一の姿勢**を指すこと(二重被覆)
4. 回転の合成が**非可換**であること
5. ジンバルロックが**オイラー角の座標特異点**であって、回転そのものの病ではないこと
6. Slerp の正体が**指数写像**であり、角速度一定の測地線であること

## 2. 規約(前提条件)

> 本章は全実装が従う前提です。ここが曖昧なまま実装すると、画面の回転方向が理論と食い違い、教材としての価値が失われます。

### 2.1 座標系

- **Unity 左手系 Y-up**。基底は $\mathbf{x}=(1,0,0)$ 右、$\mathbf{y}=(0,1,0)$ 上、$\mathbf{z}=(0,0,1)$ 前(画面奥)
- 外積の**成分式は右手系と同一**($\mathbf{x} \times \mathbf{y} = \mathbf{z}$)。ただし基底が左手系であるため、**幾何的な巻き方は左ねじ**になる

### 2.2 回転の正の向き

**左ねじ**とする。左手の親指を軸 $+\mathbf{n}$ に向けたとき、指の巻く向きが正。すなわち $+\mathbf{n}$ 側から原点を見下ろして**時計回り**が正。

> **注記(シーン内解説に明記すること)**: 数学の教科書は右手系を採り、$+\mathbf{n}$ から見て反時計回りを正とする。**向きが逆に見えるのは基底の handedness という規約の差であり、四元数代数そのものは一切変わらない**。四元数の積の規則 $ij=k$ も、$q v q^*$ という作用の形も同一である。この一点を混同させてはならない。

### 2.3 四元数

- $q = w + xi + yj + zk$、$i^2 = j^2 = k^2 = ijk = -1$、$ij = k,\; jk = i,\; ki = j$(**ハミルトン積**)
- 格納順は Unity に合わせ **`(x, y, z, w)`**。自前型も同順とし、変換時の取り違えを防ぐ
- 姿勢を表すのは**単位四元数** $|q| = 1$ のみ

### 2.4 作用・軸角・合成

| 概念 | 定義 |
| --- | --- |
| 回転作用 | $v' = q \otimes \tilde{v} \otimes q^{*}$、ただし $\tilde{v} = (0, \mathbf{v})$ |
| 軸角表現 | $q = \left(\cos\tfrac{\theta}{2},\; \sin\tfrac{\theta}{2}\,\mathbf{n}\right)$、$|\mathbf{n}| = 1$ |
| 合成 | $q_{\text{total}} = q_2 \otimes q_1$ は「$q_1$ を**先**に、$q_2$ を**後**に」適用。Unity の `q2 * q1` と一致 |
| 逆回転 | $q^{-1} = q^{*}$($|q|=1$ のとき) |

### 2.5 オイラー角

Unity 準拠。`Quaternion.Euler(x, y, z)` は **Z → X → Y の順に適用**する。行列としては

$$R = R_y(\text{yaw}) \cdot R_x(\text{pitch}) \cdot R_z(\text{roll})$$

(列ベクトルに右から作用するため、最右の $R_z$ が最初に効く)。

**この規約は前提として書き下すだけでなく、2.4・2.5 の等式そのものを 6.3 のテストで検証すること。** 規約を主張で済ませてはならない。

## 3. 数理定義

実装が参照する式を集約します。すべて 2章の規約下で成立します。

### 3.1 指数・対数写像

純虚四元数 $\tilde{u} = (0, \mathbf{u})$ に対し

$$\exp(\tilde{u}) = \left(\cos|\mathbf{u}|,\; \frac{\sin|\mathbf{u}|}{|\mathbf{u}|}\mathbf{u}\right), \qquad \log(q) = \left(0,\; \frac{\theta}{2}\mathbf{n}\right),\quad \theta = 2\,\mathrm{atan2}(|\mathbf{v}|, w)$$

$|\mathbf{u}| \to 0$ および $|\mathbf{v}| \to 0$ で $0/0$ が生じる。これは**除去可能特異点**であり、テイラー展開 $\sin|\mathbf{u}|/|\mathbf{u}| \to 1 - |\mathbf{u}|^2/6$ で退避する。**真の特異点と見かけの特異点の別**は、Ch.5 の解説対象に含める。

### 3.2 球面線形補間 (Slerp)

$$\mathrm{slerp}(q_0, q_1; t) = \frac{\sin((1-t)\Omega)}{\sin\Omega}q_0 + \frac{\sin(t\Omega)}{\sin\Omega}q_1, \qquad \cos\Omega = \langle q_0, q_1 \rangle$$

$\langle\cdot,\cdot\rangle$ は4次元内積。等価な指数写像形:

$$\mathrm{slerp}(q_0, q_1; t) = q_0 \otimes \exp\!\left(t \log(q_0^{*} \otimes q_1)\right)$$

**最短経路補正**: $\langle q_0, q_1 \rangle < 0$ のとき $q_1 \leftarrow -q_1$ とする。これを**トグルで無効化できる**こと(仕様、5.5参照)。

### 3.3 回転姿勢の時間発展

$$\dot{q} = \tfrac{1}{2}\,\tilde{\omega}_{\text{world}} \otimes q \qquad\text{(ワールド系角速度)}$$
$$\dot{q} = \tfrac{1}{2}\,q \otimes \tilde{\omega}_{\text{body}} \qquad\text{(ボディ系角速度)}$$

$\tilde{\omega} = (0, \boldsymbol{\omega})$。これらは Unity の `Space.World` / `Space.Self` に対応する。

$\boldsymbol{\omega}$ が定数のとき厳密解は

$$q(t) = \exp\!\left(\tfrac{1}{2}\tilde{\omega}t\right) \otimes q_0$$

すなわち **Slerp の正体は指数写像であり、角速度一定の測地線**である。

### 3.4 ジンバルロックのヤコビアン

ZXY 規約において、オイラー角速度から角速度へのヤコビアン $E$ は

$$\det E = \cos(\text{pitch}) \quad (\text{符号は規約による})$$

$\text{pitch} = \pm 90°$ で $\mathrm{rank}$ が 3 から 2 に落ち、自由度が1つ失われる。これは**写像の座標特異点**であり、$SO(3)$ 上の点としては何ら特異ではない。

### 3.5 アークボール

画面上のドラッグを球面上の2点 $\mathbf{p}_0 \to \mathbf{p}_1$ に写し、両者を移す最短回転を

$$q = \mathrm{normalize}\left(1 + \mathbf{p}_0 \cdot \mathbf{p}_1,\; \mathbf{p}_0 \times \mathbf{p}_1\right)$$

とする。導出: $(1 + \cos\theta,\; \sin\theta\,\mathbf{a}) = 2\cos\tfrac{\theta}{2}\left(\cos\tfrac{\theta}{2},\; \sin\tfrac{\theta}{2}\mathbf{a}\right)$。

**掴んだ点がカーソルに追従する**この $\theta$ 版を採用する(地球儀の手触りと一致するため)。Shoemake 原典の $2\theta$ 版 $q = (\mathbf{p}_0 \cdot \mathbf{p}_1,\; \mathbf{p}_0 \times \mathbf{p}_1)$ は採らない。

## 4. 画面構成 ―― 三層の同心構造

「儀」の本体は、以下の三層です。

### 4.1 内核 (Core) ―― 回転された結果

- `Dice.fbx`(既存アセット)。**出目があることが本質**で、姿勢の違いが一意に読める
- ボディ座標軸(RGB = X/Y/Z)を重畳表示

### 4.2 中殻 (Globe) ―― 軸角表現の幾何学的写像

**これが地球儀メタファーの実体であり、装飾ではない。** 回転軸 $\mathbf{n}$ は $S^2$ 上の一点、すなわち緯度経度で指せる ―― ゆえに軸は「地軸」として球を貫く。

| 要素 | 内容 |
| --- | --- |
| グリッド球 | ワールド固定の $S^2$ 緯度経度ワイヤ。基準系を与える |
| 極 | 回転軸 $\mathbf{n}$ が球面を貫く2点($\mathbf{n}$ と $-\mathbf{n}$)。$q$ に応じて動く |
| 地標ピン | 世界固定の基準点 $\mathbf{p}_0$ と、その像 $q\mathbf{p}_0$。両点を結ぶ軸周りの**小円弧**を掃く。「点が $q$ でどこへ運ばれるか」を見せる(地球儀の手触り) |
| 角度ゲージ | 軸 $\mathbf{n}$ に**直交する大円**上の分度器。常に最大半径で角 $\theta$ を読ませる計器。ピンとは役割を分離する |
| 半角演示 | 角 $\theta/2$ で交わる二枚の鏡面。像が $\theta$ 回ることを示す(Ch.1) |

**基準点 $\mathbf{p}_0$ の既定と退化の扱い(決定)**

掃き小円の半径は $\sin\alpha$($\alpha = \angle(\mathbf{p}_0, \mathbf{n})$)であり、$\mathbf{p}_0 \parallel \mathbf{n}$ で $0$ に退化する。これは**正しさではなく視認性の問題**であり、以下で回避する。

- **既定 $\mathbf{p}_0$**: グリッドの緯度0°・経度0°、すなわち**カメラに正対する赤道上の点**。Unity 既定カメラ(原点を $-Z$ から見る)では世界座標 $(0,0,-1)$。赤道に置くことで、既定の垂直寄り軸に対し $\alpha \approx 90°$ となり小円が最大に見える。
- **ピンとゲージの役割分離**: ピンは「$q$ が点をどう動かすか」(作用)、ゲージは「$\theta$ はいくつか」(計量)を担う。ピンが退化(軸に近づき小円が縮む)しても、ゲージは常に最大半径で $\theta$ を読ませる。
- **角度ゲージのゼロ基準**: $\mathbf{p}_0$ を $\mathbf{n}$ 直交平面へ射影した $\hat{\mathbf{g}}_0 = \mathrm{normalize}(\mathbf{p}_0 - (\mathbf{p}_0\cdot\mathbf{n})\mathbf{n})$。$\mathbf{p}_0 \parallel \mathbf{n}$ の退化時のみ、カメラ右方向(なければ世界 $X$)の射影へ退避する。ゲージはここから $\mathbf{n}$ 周りに $\theta$ 掃く。

### 4.3 外殻 (Rotation Space Ball) ―― 回転空間そのもの

四元数は $S^3$ に住むため直接は見えない。ベクトル部を取って**半径1の中身入りボール**に落とす。

| 模型 | 写像 | 性質 |
| --- | --- | --- |
| 四元数ベクトル部模型(**既定**) | $\mathbf{p} = \sin\tfrac{\theta}{2}\mathbf{n}$ | $(x,y,z)$ そのもの。$q$ と $-q$ が**中心対称**の位置に現れる |
| 回転ベクトル模型 | $\mathbf{p} = \theta\mathbf{n}/\pi$ | 半径が角に比例(等尺)。恒等回転からの測地線・等角速度運動が**放射直線** |

**既定はベクトル部模型。トグルで切り替える(決定)。**

- **既定にベクトル部模型を採る理由**: 表示点が四元数のベクトル部そのもの($|\mathbf{p}| = \sin\tfrac{\theta}{2} \le 1$、無スケールで単位球に収まる)であること。加えて $\mathbf{v}(-q) = -\mathbf{v}(q)$ ゆえ **$q$ と $-q$ が中心対称の位置・反転色で現れ、Ch.2 の二重被覆が「点の中心対称」として一挙に見える**。この演出はベクトル部模型でしか素直に成立しない(回転ベクトル模型では $-q$ が同一放射線上の別半径に来て中心対称にならない)。
- **Ch.5–6 で回転ベクトル模型へ切替**: ベクトル部模型は半径 $\sin\tfrac{\theta}{2}$ ゆえ、$\dfrac{d}{d\theta}\sin\tfrac{\theta}{2} = \tfrac12\cos\tfrac{\theta}{2} \to 0$($\theta\to\pi$)で 180° 近傍が表面へ圧縮される。回転ベクトル模型は半径が $\theta$ に比例して等尺で、**等角速度運動 = 中心からの放射直線を一定速度**で描く。指数写像・測地線を語る段はこちらが忠実。

構造:

- **中心** = 無回転
- **表面** = 180°回転
- **表面上の対蹠点は同一の回転**($\mathbf{n}$ の180°回転 $=$ $-\mathbf{n}$ の180°回転)

この貼り合わせで現れるのが **$RP^3$**。軌跡が表面に達したら対蹠点から現れる(ワープ)ように描画すること ―― これが $RP^3$ の実体であり、v1 で最も見せる価値のある演出である。

$w$ の符号は**色**で表す($w \ge 0$ 暖色 / $w < 0$ 寒色)。$q$ と $-q$ は**中心対称の位置に、反転した色で**現れる。

### 4.4 情報パネル

単独利用ゆえ情報密度を優先する。常時表示:

- $q = (w, x, y, z)$ の数値 + バー
- 軸角表示 $(\mathbf{n}, \theta)$
- オイラー角表示(ZXY)
- 回転行列(切替表示)

## 5. 章立て

全6章。章の切替機構(`ChapterNavigator`)のみ必須UIとする。

### 5.1 Ch.1 軸と角

- **目的**: 四元数の4成分が軸と角に分解して読めること。半角の理由。
- **操作**: アークボールでドラッグ回転(3.5)。ドラッグ中は瞬間回転軸を表示。
- **演出**: 中殻の極と掃き円弧が追従。$w = \cos(\theta/2)$、$|\mathbf{v}| = \sin(\theta/2)$ をバーで対比。
- **半角演示**: 二枚の鏡モデル。「$\theta/2$ で交わる二枚の鏡に映せば像は $\theta$ 回る」= 回転は**二つの鏡映の合成**であり、それが半角の根拠。

### 5.2 Ch.2 二重被覆

- **目的**: $q$ と $-q$ が同一姿勢を指すこと。$S^3 \to SO(3)$ が 2:1 であること。
- **操作**: 符号反転ボタン。
- **演出**: 内核の姿勢は**不動**。数値パネルは全成分が反転。外殻の点は**対蹠へ跳び、色が反転**。
- **要点**: 姿勢空間は $S^3$ ではなく $RP^3$ である。

### 5.3 Ch.3 合成の非可換性

- **目的**: $q_2 \otimes q_1 \neq q_1 \otimes q_2$。
- **演出**: サイコロを**二体並置**し、一方に X→Y、他方に Y→X を同角で適用。**出目が食い違う**。
- **要点**: 非可換性は式で説くより出目で示すほうが速い。既存 `Dice.fbx` が最も活きる章。
- **操作**: 合成順の入替トグル、各回転の軸・角スライダ。

### 5.4 Ch.4 オイラー角とジンバルロック

- **目的**: ジンバルロックが**座標特異点**であり、回転そのものの病ではないこと。
- **演出**: 3重ジンバルリング(物理的ジンバルの実体)。$\text{pitch} \to \pm 90°$ で外環と内環が**同一平面に縮退**し、赤くハイライト。
- **数値**: $\det E = \cos(\text{pitch})$ を常時表示し、$0$ へ落ちるのを見せる。
- **対比**: 同一姿勢を四元数で保持した内核は**何も起きない**。これが要点。

### 5.5 Ch.5 補間

- **目的**: Slerp の性質と、二重被覆の実害。
- **演出**: **三体同時走行** ―― Slerp / Nlerp / オイラー角補間。軌道の違いを外殻の経路として描く。
- **グラフ**: 角速度 $|\boldsymbol{\omega}(t)|$。Slerp のみ一定になる。
- **最短経路補正トグル**: **切れること**が仕様。切れば $\langle q_0, q_1 \rangle < 0$ のとき遠回り(>180°)を回り出す。Ch.2 の二重被覆が実害として現れる瞬間。
- **副題**: $\Omega \to 0$ の $0/0$ は**除去可能特異点**。真の特異点との別を示す。

### 5.6 Ch.6 角速度と微分方程式

- **目的**: $\dot{q} = \tfrac{1}{2}\tilde{\omega} \otimes q$ と、Slerp = 指数写像の正体。
- **操作**: $\boldsymbol{\omega}$ スライダ。ワールド系 / ボディ系の切替(= `Space.World` / `Space.Self`)。
- **演出**: 剛体が回り続ける。二つの系の違いが一目で分かる。
- **積分器**: Euler法 / RK4 を切替。
- **グラフ**: $|q| - 1$ の漂流。正規化トグルを切ると発散していく。**毎フレーム正規化が要る理由を理論から示す。**

### 6.2 自前実装の方針

Unity 組み込み `Quaternion` は内部が不可視で、`Slerp` の中身も `exp`/`log` も見せられない。ゆえに **数学的定義そのままの `Quat` 型を主とする**。

- `readonly struct Quat`、格納順 `(x, y, z, w)`(2.3)
- 積・共役・`exp`・`log`・`slerp`・`nlerp`・軸角変換・オイラー角変換をすべて自前
- **内部量(半角、内積 $\Omega$、$|q|$ の誤差)をUI・グラフへ開放する**こと ―― これが自前実装を採る唯一の目的である
- Unity 側への受け渡しは `Quat → UnityEngine.Quaternion` の変換関数一点に集約する

### 6.3 検証テスト(EditMode)

**規約は主張ではなくテストで担保する。** 最低限、以下を検証すること。

| 検証項目 | 内容 |
| --- | --- |
| 軸角の一致 | 自前 `FromAxisAngle(n, θ)` == `Quaternion.AngleAxis(θ, n)` |
| 合成順の一致 | 自前 `q2 * q1` == Unity `q2 * q1`、かつ `(q2*q1)*v == q2*(q1*v)` |
| オイラー規約 | `Quaternion.Euler(x,y,z)` == `AngleAxis(y,up) * AngleAxis(x,right) * AngleAxis(z,forward)` |
| 作用の一致 | $q \otimes \tilde{v} \otimes q^{*}$ の結果 == `Quaternion * Vector3` |
| Slerp の一致 | 自前 `Slerp`(最短経路補正あり) == `Quaternion.Slerp` |
| 二重被覆 | $q$ と $-q$ が同一のベクトル像を与える |
| exp/log 往復 | `exp(log(q)) == q`(単位四元数、$|\mathbf{v}| \to 0$ の縮退近傍を含む) |
| 除去可能特異点 | $\Omega \to 0$、$|\mathbf{v}| \to 0$ で `NaN` を出さない |

浮動小数の比較は許容誤差付きで行うこと。
