## 1. 設計方針

### 1.1 中核原則 ―― シーンを割らず、儀を語らせる

**素朴案(各セクションごとに図解シーンを新規作成)は採らない。** 理由は理論的だ。

儀の教材価値の源泉は、**「たった一つの同じ回転対象 $q$ を、章ごとに異なる計器で覗く」**という同一性にある([`spec.md` §4](spec.md) 三層同心構造)。Ch.3 で非可換性を見せたその同じサイコロが、Ch.5 で同じ軌跡を描く ―― この連続性こそが「クォータニオンは一つの理論体系である」と無言で語る。章ごとにシーンを割れば、この同一性が壊れ、教材はただの図版集へ堕ちる。

ゆえに本案は **`QuaternionGlobe.unity` 一枚を、"解説ビート列" で駆動する**。

- **ビート(beat)** = 〈ナレーション文(二層)＋儀の状態指示〉の最小単位。1枚の"図"に相当する。
- **章(ChapterScript)** = 順序付きビート列。
- 儀そのものは常時ライブで操作可能。ビートは「今どこを見せ、何を言うか」を宣言するだけで、儀を止めはしない。

これは [`spec.md` §6.1](spec.md) が既に予定している `ChapterNavigator` / `ChapterBase` / `Ch1..Ch6` の自然な肉付けである。**ゼロから作る物は「ビート駆動の仕組み」と「本ファイルの解説文」の二つだけ。**

### 1.2 二層ナレーション ―― 直感を先、数理を掘る

各ビートは二層を持つ。

- **〔直感〕層**: 常時表示。「画面で腑に落ちる」一言。式は最小限。勉強会の聴衆・自習者が最初に読む。
- **〔数理〕層**: 折りたたみ(既定は畳む)。「掘る」と現れる導出・厳密な定義・特異点の議論。中級者向けの深掘り。壇上で開いて見せてもよいし、自習者が己の意志で開いてもよい。

**設計上の要点**: 直感層は数理層の"要約"ではなく"入口"である。直感層で「なぜ?」を立て、数理層でその「なぜ」に答える。答えを直感層で先食いしない。

### 1.3 両対応 ―― ステップ送りが講義にも自習にも効く

同一の「ビート送り(Next/Prev)」機構が、二つの使い方を同時に満たす。

- **講義**: 話者が壇上で Next を押して進む。**話者ノート**(画面外・別枠)を各ビートに持たせ、口頭補足の台本とする。話者は 444 に限らない ―― 誰が登壇しても読める中立な文とする。
- **自習**: 個人が自分のペースで Next/Prev。いつでも解説モードを抜けて自由探索(儀を直接ドラッグ)へ移り、また戻れる。

順路は**強制しない**。ビートは"推奨する視点"であって"檻"ではない。解説モード中でも儀は生きており、聴衆の「そこ、右に回して」に応えられる ―― これがスライドではなくライブの儀を使う唯一の理由だ。

### 4.1 Ch.1 ―― 軸と角 (spec 5.1)

**問い**: 4つの数 $(w,x,y,z)$ は何を意味するのか。なぜ"半角"が現れるのか。
**儀の既定**: 外殻=ベクトル部模型。姿勢 `axis=(1,2,0.5), θ=120°`(spec 検証値。$w=0.5$, $|v|=\sin 60°=0.866$)。

#### ビート1 ― 4つの数の正体
- **儀の状態**: `setPosture (1,2,0.5) 120°` / camera=CoreAndGlobe / highlight=WXYZ
- **〔直感〕** クォータニオンの4成分は、謎の4つ数ではない。**回転軸 $\mathbf{n}$**(どの向きに)と **回転角 $\theta$**(どれだけ)という、たった2つの情報を畳んだものだ。中殻を貫く地軸が $\mathbf{n}$、これから読む角が $\theta$。
- **〔数理〕** 単位四元数は軸角表現 $q = (\cos\tfrac{\theta}{2},\ \sin\tfrac{\theta}{2}\,\mathbf{n})$ を持つ(spec §2.4)。$|\mathbf{n}|=1$ ゆえ $w^2+|\mathbf{v}|^2 = \cos^2\tfrac{\theta}{2}+\sin^2\tfrac{\theta}{2}=1$。4成分は独立ではなく、単位球 $S^3$ 上の一点だ。半角 $\theta/2$ の由来はビート4で暴く。
- **〔話者ノート〕** ここで「$w$ は角、$x,y,z$ は軸方向」と早合点させない。正しくは「$w$ が角の余弦(半角)、$(x,y,z)$ が軸に半角の正弦を掛けたもの」。バーの動きで後述。

#### ビート2 ― 軸を地軸として読む
- **儀の状態**: 同姿勢 / camera=CoreAndGlobe / highlight=AxisAngle
- **〔直感〕** 回転軸 $\mathbf{n}$ は、地球儀の**地軸そのもの**だ。球面 $S^2$ 上の緯度経度で、ただ一点に指せる。軸が球を貫く二点、北極 $\mathbf{n}$ と南極 $-\mathbf{n}$ を見よ。
- **〔数理〕** $\mathbf{n}\in S^2$。これが「軸角表現の幾何学的写像」の実体だ(spec §4.2)。極は $\pm\mathbf{n}$ を球半径倍した点。**軸を $S^2$ の点として指せる**ことが、中殻を"地球儀"と呼ぶ根拠であって、装飾ではない。
- **〔話者ノート〕** $\mathbf{n}$ と $-\mathbf{n}$ の両方が極になる点に注意を促す。「どちらが正の軸か」は回転の向き(spec §2.2 左ねじ)で決まる。

#### ビート3 ― 角をゲージで読む・点を運ぶ
- **儀の状態**: 同姿勢 / camera=CoreAndGlobe / highlight=AxisAngle
- **〔直感〕** 二つの計器を分けて見る。**地標ピン**は「基準点 $\mathbf{p}_0$ が $q$ でどこへ運ばれるか」=**作用**を、軸周りの小円弧で描く。**角度ゲージ**は「その角 $\theta$ はいくつか」=**計量**を、常に最大の分度器で読む。
- **〔数理〕** ピンの掃く小円の半径は $\sin\alpha$($\alpha=\angle(\mathbf{p}_0,\mathbf{n})$)で、$\mathbf{p}_0\parallel\mathbf{n}$ で 0 に退化する(spec §4.2)。ゆえに役割を分離する ―― ゲージは $\mathbf{n}$ 直交の大円上に取り、常に半径最大で $\theta$ を読ませる。既定 $\mathbf{p}_0$ は赤道上の $(0,0,-1)$、ゼロ基準は $\hat{\mathbf{g}}_0=\mathrm{normalize}(\mathbf{p}_0-(\mathbf{p}_0\cdot\mathbf{n})\mathbf{n})$。
- **〔話者ノート〕** 「ピンが縮んでもゲージは縮まない」を実演。軸を鉛直近くへ動かすと小円が痩せるが、ゲージは動じない ―― 作用と計量は別物という設計思想。

#### ビート4 ― 半角の核心：二枚の鏡（MIRRORS）
- **儀の状態**: `demos=Mirrors` / camera=CoreAndGlobe / highlight=HalfAngle(`w=cos(θ/2)`, `|v|=sin(θ/2)` を強調)
- **〔直感〕** なぜ"半分"なのか。**回転とは、二枚の鏡に像を映す操作**だからだ。鏡が角 $\theta/2$ で交わっていると、像は $\theta$ だけ回る ―― 鏡の間の角の**2倍**。この「2倍」の裏返しが、四元数に現れる「半角」の正体だ。
- **〔数理〕** 平面鏡映は対合 $\mathbf{v}'=\mathbf{v}-2(\mathbf{v}\cdot\mathbf{m})\mathbf{m}$(spec §3.6-E)。法線が角 $\varphi$ で交わる二枚 $\mathbf{m}_1\to\mathbf{m}_2$ の合成は、軸 $\mathbf{m}_1\times\mathbf{m}_2$ 周り角 $2\varphi$ の回転になる。`ReflectionPair(n, θ)` は $\varphi=\theta/2$ を取り、合成作用が `FromAxisAngle(n, θ)` と一致する(EditMode で検証済み・spec §6.3-E)。バーで $w=\cos\tfrac{\theta}{2}$、$|\mathbf{v}|=\sin\tfrac{\theta}{2}$ を対比せよ ―― $\theta$ ではなく $\theta/2$ の三角比が成分に立つ。
- **〔話者ノート〕** ここが Ch.1 の山。「四元数が半角なのは実装の都合ではなく、回転が二鏡映であることの必然」と締める。次章(二重被覆)への布石: 半角ゆえ $\theta$ と $\theta+2\pi$ で符号が反転する。

### 4.2 Ch.2 ―― 二重被覆 (spec 5.2)

**問い**: $q$ と $-q$ は違う四元数だ。なのに同じ姿勢を指す。なぜか。
**儀の既定**: 外殻=ベクトル部模型(**この演出はベクトル部模型でしか素直に成立しない** ―― spec §4.3)。

#### ビート1 ― 符号を反転しても、出目は動かない
- **儀の状態**: `onEnter: q ← -q`(符号反転) / camera=Overview / highlight=WXYZ
- **〔直感〕** $q$ の**全4成分の符号を反転**する。数値パネルは総て反転した。だが内核 ―― サイコロの出目は、**微動だにしない**。
- **〔数理〕** 回転作用は $v'=q\otimes\tilde{v}\otimes q^{*}$(spec §2.4)。$-q$ を代入すると $(-q)\otimes\tilde{v}\otimes(-q)^{*}=(-1)(-1)\,q\otimes\tilde{v}\otimes q^{*}=q\otimes\tilde{v}\otimes q^{*}$。**符号が二度現れて相殺する**。ゆえに $q$ と $-q$ は同一の $SO(3)$ 作用。
- **〔話者ノート〕** 「符号が二回効くから消える」を強調。これが $S^3\to SO(3)$ が **2:1**(二重被覆)である代数的な理由。

#### ビート2 ― -q はどんな回転か
- **儀の状態**: 同左 / camera=CoreAndGlobe / highlight=AxisAngle
- **〔直感〕** $-q$ を軸角に読み直すと、**逆向きの軸 $-\mathbf{n}$ の周りに、$2\pi-\theta$ だけ回る**回転になっている。$\mathbf{n}$ 周りに $\theta$ 回るのと、$-\mathbf{n}$ 周りに $2\pi-\theta$ 回るのは ―― 同じ姿勢だ。
- **〔数理〕** $q=(\cos\tfrac{\theta}{2},\sin\tfrac{\theta}{2}\mathbf{n})$ に対し $-q=(-\cos\tfrac{\theta}{2},-\sin\tfrac{\theta}{2}\mathbf{n})$。これは $(\cos\tfrac{2\pi-\theta}{2},\ \sin\tfrac{2\pi-\theta}{2}(-\mathbf{n}))$ に等しい($\cos(\pi-\tfrac{\theta}{2})=-\cos\tfrac{\theta}{2}$, $\sin(\pi-\tfrac{\theta}{2})=\sin\tfrac{\theta}{2}$)。すなわち軸 $-\mathbf{n}$・角 $2\pi-\theta$。半角表現(Ch.1)がこの符号の対称性を生んでいる。
- **〔話者ノート〕** 「四元数は $\theta$ を $[0,4\pi)$ で一周する(半角ゆえ実回転の二周ぶん)」。$2\pi$ 回すと $q=-1$、$4\pi$ でようやく $q=+1$ へ戻る ―― これがスピノルの二価性。深掘り希望時のみ触れる。

#### ビート3 ― 外殻では対蹠へ跳ぶ
- **儀の状態**: `ballModel=VectorPart` / camera=SpaceBall / highlight=WXYZ
- **〔直感〕** 回転空間(外殻ボール)で見ると一目瞭然だ。$q$ の点と $-q$ の点は、**原点をはさんで正反対**(中心対称)の位置にあり、**色が反転**(暖色↔寒色)している。符号反転ボタンを押すと、点は対蹠へ跳ぶ。
- **〔数理〕** ベクトル部模型は $\mathbf{p}=\sin\tfrac{\theta}{2}\mathbf{n}=(x,y,z)$(spec §4.3)。$\mathbf{v}(-q)=-\mathbf{v}(q)$ ゆえ中心対称。$w$ の符号が色(暖/寒)ゆえ、反転で色も裏返る。**回転ベクトル模型では中心対称にならない**(spec §4.3)から、この演出はベクトル部模型専用。
- **〔話者ノート〕** 「なぜ既定がベクトル部模型か」の答えがここ。二重被覆が"点の中心対称"として一挙に見える。

#### ビート4 ― 姿勢の住処は S³ ではなく RP³
- **儀の状態**: 同左 / camera=SpaceBall / highlight=None
- **〔直感〕** $q$ と $-q$ が同じ姿勢なら、球面 $S^3$ の対蹠点どうしを**同一視して貼り合わせ**なければならない。そうして現れる空間が **$RP^3$**(実射影空間)。これが回転姿勢の真の住処だ。
- **〔数理〕** $SO(3)\cong S^3/\{\pm 1\}=RP^3$。二重被覆 $S^3\to RP^3$ は 2:1。外殻で軌跡が表面(180°)に達したとき対蹠から現れる**ワープ**は、この貼り合わせの実体である(spec §4.3 ―― v1 で最も見せる価値のある演出)。
- **〔話者ノート〕** Ch.5 への伏線: 「この対蹠の貼り合わせを補間器が知らないと、遠回りが起きる」。二重被覆は美しいだけでなく、実害を生む(Ch.5 で回収)。

### 4.3 Ch.3 ―― 合成の非可換性 (spec 5.3)

**問い**: 二つの回転を「先に A、後に B」と「先に B、後に A」で、結果は同じか。
**儀の既定**: 内核=サイコロ二体並置(spec §5.3 ―― 既存 `Dice.fbx` が最も活きる章)。

#### ビート1 ― 同じ二回転、順序だけ違える
- **儀の状態**: 二体サイコロ / camera=Overview / highlight=None
- **〔直感〕** 同一の二つの回転 ―― X軸まわりとY軸まわり ―― を用意する。左のサイコロには「X→Y」、右には「Y→X」の順で適用する。回す量は完全に同じ。順序だけが違う。
- **〔数理〕** 合成は $q_{\text{total}}=q_2\otimes q_1$ で「$q_1$ を先、$q_2$ を後」(spec §2.4、Unity `q2*q1` と一致)。左が $q_Y\otimes q_X$、右が $q_X\otimes q_Y$。
- **〔話者ノート〕** 「順序で結果が変わるか?」を聴衆に問うてから次のビートで送る。予想させると効く。

#### ビート2 ― 出目が食い違う
- **儀の状態**: 二体サイコロ(適用後) / camera=CoreAndGlobe / highlight=WXYZ
- **〔直感〕** 出目が、はっきり違う。同じ回転を同じだけ、順序を変えて掛けただけで、姿勢が別物になった。これが**非可換**だ。式で説くより、出目が語る。
- **〔数理〕** 一般に $q_2\otimes q_1\neq q_1\otimes q_2$。根はハミルトン積の非可換性 $ij=k$ かつ $ji=-k$(spec §2.3)。二つの $q$ の数値パネルを並べれば、$w$ すら一致しないことがある。
- **〔話者ノート〕** 「行列の積が非可換なのと同じ」と橋渡ししてよいが、四元数はそれを4成分で担う。

#### ビート3 ― 非可換の源は外積
- **儀の状態**: 二体サイコロ / camera=CoreAndGlobe / highlight=None
- **〔直感〕** なぜ食い違うのか。二つの回転を"混ぜる"と、順序を入れ替えたときの差が、**二つの軸の外積 $\mathbf{n}_1\times\mathbf{n}_2$ の向き**に現れるからだ。外積は順序で符号が変わる ―― それが非可換の芯。
- **〔数理〕** 微小回転 $q_i\approx(1,\tfrac12\boldsymbol{\phi}_i)$ の交換子は $q_2 q_1 - q_1 q_2$ のベクトル部が $\tfrac12\boldsymbol{\phi}_1\times\boldsymbol{\phi}_2$ に比例する。純虚四元数の積 $\tilde{u}\tilde{v}=-\mathbf{u}\cdot\mathbf{v}+\mathbf{u}\times\mathbf{v}$ の外積項がそのまま非可換性を担う。これは $\mathfrak{so}(3)$ のリー括弧 $[\boldsymbol{\phi}_1,\boldsymbol{\phi}_2]=\boldsymbol{\phi}_1\times\boldsymbol{\phi}_2$ に他ならない。
- **〔話者ノート〕** 深掘り希望者にのみリー代数へ。通常は「外積が順序で符号を変える」で止めてよい。

### 4.4 Ch.4 ―― オイラー角とジンバルロック (spec 5.4)

**問い**: ジンバルロックとは何が"ロック"されるのか。回転そのものの欠陥なのか。
**儀の既定**: `demos=Gimbal`(3重リング)。内核は四元数駆動のまま並置。

#### ビート1 ― 三重の輪
- **儀の状態**: `demos=Gimbal` / camera=Gimbal / highlight=Euler
- **〔直感〕** オイラー角は、姿勢を**三重のジンバルリング**で作る。外環が yaw、中環が pitch、内環が roll。三つの角を順に回して、どんな姿勢も表す ―― はずだった。
- **〔数理〕** ZXY 規約(spec §2.5)で累積回転は $q_{\text{outer}}=q_y$, $q_{\text{middle}}=q_y\otimes q_x$, $q_{\text{inner}}=q_y\otimes q_x\otimes q_z$(`GimbalStages`, spec §3.6-G)。$q_{\text{inner}}=\mathrm{FromEuler}(p,y,r)$ と一致(検証済み)。
- **〔話者ノート〕** 各環がどの角を担うかを指で追わせる。次で pitch を 90° へ倒す。

#### ビート2 ― pitch を 90° へ倒すと自由度が消える
- **儀の状態**: `setPosture pitch→90°`(アニメ) / camera=Gimbal / highlight=DetE
- **〔直感〕** pitch を 90° へ倒していくと ―― 外環(yaw)と内環(roll)の回転軸が**重なる**。二つの輪が同じ回り方しかできなくなり、**自由度が一つ消える**。これがロックだ。二つの環が赤く警告する。
- **〔数理〕** オイラー角速度からワールド角速度へのヤコビアン $E=(R_y\hat{\mathbf{x}}\,|\,\hat{\mathbf{y}}\,|\,R_yR_x\hat{\mathbf{z}})$(spec §3.6-F)。$\det E=\cos(\text{pitch})$。pitch=$\pm90°$ で pitch 回転が roll 軸 $\hat{\mathbf{z}}$ を $\mp\hat{\mathbf{y}}$ へ倒し、**第2列(yaw)と第3列(roll)が平行**化、$\mathrm{rank}\,E:3\to2$。
- **〔話者ノート〕** 「外環と内環の軸が揃う」を必ず名指しで。当初 spec が第1列と誤記しテストが検出した経緯([`2026-07-18-desktop-session.md`](../.wip/2026-07-18-desktop-session.md))は、まさに"どの環か"が要である証。

#### ビート3 ― det E = cos(pitch) が 0 へ落ちる
- **儀の状態**: 同左 / camera=Gimbal / highlight=DetE
- **〔直感〕** 計器の $\det E=\cos(\text{pitch})$ を見よ。pitch が 90° へ近づくにつれ、この値がゼロへ落ちていく。ゼロになった瞬間が、失われた自由度そのものの目盛りだ。
- **〔数理〕** $\det E=0\iff$ 三本の軸が一次従属 $\iff$ 三角(オイラー角)から角速度への写像が全射でなくなる。ゼロは連続的に近づく ―― ロックは崖ではなく、その手前で既に**"効きの悪い"領域**が広がっている(条件数の悪化)。
- **〔話者ノート〕** 実機(カメラジンバル・航空機)で「ジンバルロック手前で操作が過敏になる」現象の説明に接続できる。

#### ビート4 ― 核心：四元数の内核は何も起きない
- **儀の状態**: `demos=Gimbal` ＋ 内核(四元数駆動)を強調 / camera=Overview / highlight=WXYZ
- **〔直感〕** 同じ姿勢を**四元数で保持した内核**を見よ ―― 何も起きない。滑らかに通り抜ける。ロックはオイラー角という**"地図の描き方"の特異点**であって、回転そのものの病ではない。
- **〔数理〕** ジンバルロックは**座標特異点**(chart singularity)。姿勢多様体 $SO(3)$(あるいは $RP^3$)上の点としては、pitch=90° の姿勢は他のどの姿勢とも同格で、何ら特異ではない。特異なのは $(p,y,r)\mapsto SO(3)$ という**座標写像**の方。$S^2$ の極で経度が定まらないのと同根の、**地図の縮退**である。四元数は $SO(3)$ を大域的に(二重被覆で滑らかに)覆うため、この縮退を持たない。
- **〔話者ノート〕** Ch.4 の主眼。「ロックは回転の欠陥ではなく座標の欠陥」を、二つの内核(オイラー環 vs 四元数コア)の対比で締める。

### 4.5 Ch.5 ―― 補間 (spec 5.5)

**問い**: 姿勢Aから姿勢Bへ滑らかに繋ぐ。三つのやり方は何が違うのか。二重被覆はここで牙を剥く。
**儀の既定**: `demos=Interp|Graph`(三体走行＋角速度グラフ)。外殻=既定はベクトル部模型、測地線を語る段で回転ベクトル模型へ切替可(spec §4.3)。

#### ビート1 ― 三体同時走行
- **儀の状態**: `demos=Interp|Graph`, `InterpRace.run=true` / camera=SpaceBall / highlight=None
- **〔直感〕** 姿勢Aから姿勢Bへ、三つのやり方で同時に補間する。**Slerp**(teal)、**Nlerp**(orange)、**オイラー角補間**(magenta)。外殻ボールに三本の軌跡が描かれ、三体のマーカーが並走する。
- **〔数理〕** Slerp $=\dfrac{\sin((1-t)\Omega)}{\sin\Omega}q_0+\dfrac{\sin(t\Omega)}{\sin\Omega}q_1$($\cos\Omega=\langle q_0,q_1\rangle$, spec §3.2)。Nlerp は線形補間の正規化。Euler は成分ごと最短差分の線形補間を `FromEuler` に通す(`EulerInterp`, spec §3.6-H)。三体は [`InterpRace.Evaluate`](../Assets/QuaternionViewer/Scripts/Visualization/InterpRace.cs) が同一 $q_0,q_1$ から生成。
- **〔話者ノート〕** 軌跡の形の違い(Slerp は大円=直線的、他は歪む)をまず目で。数値は次のグラフで。

#### ビート2 ― 角速度グラフ：Slerp だけが一定
- **儀の状態**: 同左 / camera=SpaceBall＋グラフ注視 / highlight=None
- **〔直感〕** 右下の角速度グラフ $|\boldsymbol{\omega}(t)|$ を見よ。**Slerp だけが真っ平ら**(一定)。Nlerp と Euler は途中で速くなったり遅くなったりする。Slerp は"最短の道を等速で"進む唯一の補間だ。
- **〔数理〕** $|\boldsymbol{\omega}|\approx\dfrac{2|\log(q(t)^{*}\otimes q(t+\Delta t))|}{\Delta t}$(`AngularSpeed`, spec §3.6-H)を [`InterpRace.SampleSpeeds`](../Assets/QuaternionViewer/Scripts/Visualization/InterpRace.cs) が計測。Slerp は $SO(3)$ の測地線(定速大円)ゆえ $|\boldsymbol{\omega}|=\Omega$ 一定。Nlerp は弦を等速で刻むため中央で角速度が落ち、Euler は座標の歪みを負う。
- **〔話者ノート〕** 「一定角速度」は次章(Ch.6)の「Slerp=指数写像」への直接の伏線。

#### ビート3 ― 最短経路補正を切る：二重被覆の実害
- **儀の状態**: `onEnter: 補正 OFF` / camera=SpaceBall / highlight=None
- **〔直感〕** ここで最短経路補正を**切る**。すると Slerp が突然**遠回り**を始める ―― 180°を超えて、ぐるりと長い方を回る。Ch.2 で見た $q$ と $-q$ の取り違えが、ここで**実害として噴出**する。
- **〔数理〕** 補正は $\langle q_0,q_1\rangle<0$ のとき $q_1\leftarrow-q_1$ とし、$\Omega\le\pi/2$ 側(短弧)を選ぶ(spec §3.2)。切ると同じ姿勢を指す $-q_1$ を選び損ね、$\Omega>\pi/2$ の長弧を通る ―― $RP^3$ で近い二点が、$S^3$ では遠回りに繋がれる。**二重被覆を無視した代償**。
- **〔話者ノート〕** Ch.2 の「対蹠の貼り合わせを補間器が知らないと遠回り」の回収。ここが Ch.2↔Ch.5 を結ぶ山場。

#### ビート4 ― 見かけの特異点：Ω→0 の 0/0
- **儀の状態**: `setPosture: q0≈q1`(両端を近づける) / camera=SpaceBall / highlight=None
- **〔直感〕** 補正を戻し、姿勢Aと姿勢Bを**ほぼ一致**させる。Slerp の式は $\sin\Omega/\sin\Omega$ が $0/0$ になりそうだが ―― 破綻しない。これは"割り切れる"**見かけの特異点**だ。Ch.4 の本物の特異点とは違う。
- **〔数理〕** $\Omega\to0$ で $\dfrac{\sin(t\Omega)}{\sin\Omega}\to t$(テイラー $\sin x/x\to1-x^2/6$、spec §3.1)。**除去可能特異点**であり、極限は線形補間へ連続に繋がる。対して Ch.4 のジンバルロックは座標写像の階数が落ちる**真の縮退**。両者を混同してはならぬ ―― 「$0/0$ の顔をしていても、退避できる偽の特異点」と「退避できない真の特異点」の別こそ、本章の裏テーマだ。
- **〔話者ノート〕** 本章の要。特異点の分類(除去可能 vs 本質的/座標)を一言添えると、Ch.4 と Ch.5 が一本の糸で結ばれる。

### 4.6 Ch.6 ―― 角速度と微分方程式 (spec 5.6)

**問い**: 回り"続ける"とはどういう式か。Slerp の正体は何か。なぜ毎フレーム正規化が要るのか。
**儀の既定**: 外殻=回転ベクトル模型(測地線=放射直線が忠実、spec §4.3)。剛体が連続回転。

#### ビート1 ― 姿勢の時間発展
- **儀の状態**: `onEnter: ω設定`, 連続回転 ON / camera=Overview / highlight=WXYZ
- **〔直感〕** 角速度 $\boldsymbol{\omega}$ を与えると、姿勢 $q$ が時々刻々と変わっていく。回転は"状態"であると同時に"運動"だ。その運動を支配する式がある。
- **〔数理〕** $\dot{q}=\tfrac12\,\tilde{\boldsymbol{\omega}}_{\text{world}}\otimes q$(ワールド系)または $\dot{q}=\tfrac12\,q\otimes\tilde{\boldsymbol{\omega}}_{\text{body}}$(ボディ系)、$\tilde{\boldsymbol{\omega}}=(0,\boldsymbol{\omega})$(spec §3.3)。係数 $\tfrac12$ は半角の分だけ(Ch.1)。積分器は [`RotationIntegrator`](../Assets/QuaternionViewer/Scripts/Core/RotationIntegrator.cs)(Euler法/RK4)。
- **〔話者ノート〕** 「$\tfrac12$ はどこから?」に Ch.1 の半角で答えられる。章がここで円環する。

#### ビート2 ― ワールド系 vs ボディ系
- **儀の状態**: `onEnter: world/body 切替` / camera=Overview / highlight=WXYZ
- **〔直感〕** 同じ $\boldsymbol{\omega}$ でも、**世界系**(外から見た固定軸まわり)と**ボディ系**(剛体に貼り付いた軸まわり)では、運動が全く違う。Unity の `Space.World` と `Space.Self` の違いそのものだ。
- **〔数理〕** 世界系は**左乗** $\tilde{\boldsymbol{\omega}}\otimes q$、ボディ系は**右乗** $q\otimes\tilde{\boldsymbol{\omega}}$(spec §3.3)。四元数積の非可換性(Ch.3)がここで運動の差として顕現する ―― 左から掛けるか右から掛けるかが、軸を世界に固定するか剛体に固定するかを決める。
- **〔話者ノート〕** Ch.3 の非可換性が"実運動の違い"として効く実例。章の相互接続を強調。

#### ビート3 ― Slerp の正体は指数写像
- **儀の状態**: `ballModel=RotationVector`, ω一定 / camera=SpaceBall / highlight=None
- **〔直感〕** $\boldsymbol{\omega}$ を一定に保つと、姿勢は外殻(回転ベクトル模型)の中を**中心からまっすぐ**、等速で進む放射直線を描く。これが測地線 ―― そして**Slerp の正体**だ。Ch.5 で「Slerp だけ角速度一定」だったのは、これだったのだ。
- **〔数理〕** $\boldsymbol{\omega}$ 定数の厳密解は $q(t)=\exp(\tfrac12\tilde{\boldsymbol{\omega}}t)\otimes q_0$(spec §3.3)。**Slerp は指数写像であり、角速度一定の測地線**。回転ベクトル模型は半径が角に比例(等尺)ゆえ、等角速度運動が中心からの放射直線として忠実に描かれる(ベクトル部模型では $\theta\to\pi$ で表面へ圧縮され歪む ―― spec §4.3)。
- **〔話者ノート〕** Ch.5 ビート2「Slerp だけ一定」の回収であり、全章の理論的な収束点。「補間・測地線・微分方程式の厳密解が同一物」と締める。

#### ビート4 ― なぜ毎フレーム正規化が要るのか
- **儀の状態**: `demos=Graph`(|q|−1 漂流), `onEnter: 正規化 OFF` / camera=Overview / highlight=QNormDrift
  - **依存(未実装)**: このビートは `GraphPlotter` の $|q|-1$ 描画モードを要する。現状は $|\boldsymbol{\omega}|$ のみ実装済み(§2.1 参照)。44 の Ch.6 実装と同時に整える。
- **〔直感〕** グラフ $|q|-1$ を見よ。数値積分を続けると、$|q|$ が少しずつ 1 からずれていく。放っておくと $q$ は単位球から落ちて姿勢が壊れる。だから**毎フレーム正規化**が要る。正規化を切ると、発散していく。
- **〔数理〕** $\dot q=\tfrac12\tilde\omega q$ の厳密解はノルムを保つ($\tfrac{d}{dt}|q|^2=2\langle q,\dot q\rangle=\langle q,\tilde\omega q\rangle=0$、$\tilde\omega$ が純虚ゆえ)。だが離散積分(Euler法)は各ステップで接空間 $T_qS^3$ の方向へ一次で踏み出すため、$S^3$ の外へ漸進的に逸脱する。RK4 は高次項まで追って逸脱を抑えるが**ゼロにはできない**。正規化は各ステップ後に $q/|q|$ で $S^3$ へ射影する処置 ―― **理論(ノルム保存)を離散化が破るから、射影で理論へ引き戻す**。
- **〔話者ノート〕** 「毎フレーム正規化は場当たりの呪文ではなく、多様体上の運動を接空間で近似することの必然的な補正」。ここで全6章 ―― 軸角・二重被覆・非可換・座標特異点・補間・微分方程式 ―― が「$q$ は $S^3$(実は $RP^3$)上に住む」という一点へ収斂する。
