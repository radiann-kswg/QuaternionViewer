# Ch.3 合成の非可換性

> 台本の正典は docs/section-guide.md §4.3。本ファイルはその画面用転記 (SSOT は §4)。
> 儀の既定: 内核=サイコロ二体並置 (spec §5.3 ―― TwinDiceRig。左=X→Y / 右=Y→X の逐次適用アニメ)。

## ◆ 同じ二回転、順序だけ違える
@demos TwinDice
@camera Overview
@highlight None
@action twinRestart

### 直感
同一の二つの回転 ―― X軸まわりとY軸まわり ―― を用意する。左のサイコロには「X→Y」、右には「Y→X」の順で適用する。回す量は完全に同じ。順序だけが違う。

### 数理
合成は q_total = q2 ⊗ q1 で「q1 を先、q2 を後」(spec §2.4、Unity の q2*q1 と一致)。左が qY ⊗ qX、右が qX ⊗ qY。

### 話者ノート
「順序で結果が変わるか?」を聴衆に問うてから、アニメが回り切るのを待って次のビートへ。もう一度見せたければこのビートへ戻れば再走行する。

## ◆ 出目が食い違う
@demos TwinDice
@camera Overview
@highlight None
@focus twin

### 直感
出目が、はっきり違う。同じ回転を同じだけ、順序を変えて掛けただけで、姿勢が別物になった。これが非可換だ。式で説くより、出目が語る。

### 数理
一般に q2 ⊗ q1 ≠ q1 ⊗ q2。根はハミルトン積の非可換性 ij = k かつ ji = -k (spec §2.3)。90°+90° の例では二体の姿勢差は 120° にもなる。

### 話者ノート
左右のサイコロを指してどの目が上を向いたか読み上げさせると効く。自由探索ドラッグは単体サイコロ用 ―― 二体は固定演出。

## ○ 非可換の源は外積
@demos TwinDice
@camera Overview
@highlight None

### 直感
なぜ食い違うのか。二つの回転を「混ぜる」と、順序を入れ替えたときの差が、二つの軸の外積 n1×n2 の向きに現れるからだ。外積は順序で符号が変わる ―― それが非可換の芯。

### 数理
微小回転 qi ≈ (1, φi/2) の交換子は q2 q1 - q1 q2 のベクトル部が (φ1×φ2)/2 に比例する。純虚四元数の積 u~ v~ = -u・v + u×v の外積項がそのまま非可換性を担う。これは so(3) のリー括弧 [φ1, φ2] = φ1×φ2 に他ならない。

### 話者ノート
深掘り希望者にのみリー代数へ。通常は「外積が順序で符号を変える」で止めてよい。
