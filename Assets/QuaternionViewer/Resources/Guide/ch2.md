# Ch.2 二重被覆

> 台本の正典は docs/section-guide.md §4.2。本ファイルはその画面用転記 (SSOT は §4)。
> 儀の既定: 外殻=ベクトル部模型 (この演出はベクトル部模型でしか素直に成立しない ―― spec §4.3)。

## ◆ 符号を反転しても、出目は動かない
@camera Overview
@highlight WXYZ
@action flipSign

### 直感
q の全4成分の符号を反転する。数値パネルは総て反転した。だが内核 ―― サイコロの出目は、微動だにしない。

### 数理
回転作用は v' = q ⊗ v~ ⊗ q* (spec §2.4)。-q を代入すると (-q) ⊗ v~ ⊗ (-q)* = (-1)(-1) q ⊗ v~ ⊗ q* = q ⊗ v~ ⊗ q*。符号が二度現れて相殺する。ゆえに q と -q は同一の SO(3) 作用。

### 話者ノート
「符号が二回効くから消える」を強調。これが S^3 → SO(3) が 2:1 (二重被覆) である代数的な理由。
(このビートに入るたび符号が反転する ―― もう一度入れば元に戻る。往復して見せてよい)

## ○ -q はどんな回転か
@camera CoreAndGlobe
@highlight AxisAngle
@focus pole+ pole-

### 直感
-q を軸角に読み直すと、逆向きの軸 -n の周りに、2π-θ だけ回る回転になっている。n 周りに θ 回るのと、-n 周りに 2π-θ 回るのは ―― 同じ姿勢だ。

### 数理
q = (cos(θ/2), sin(θ/2) n) に対し -q = (-cos(θ/2), -sin(θ/2) n)。これは (cos((2π-θ)/2), sin((2π-θ)/2)(-n)) に等しい (cos(π-θ/2) = -cos(θ/2), sin(π-θ/2) = sin(θ/2))。すなわち軸 -n・角 2π-θ。半角表現 (Ch.1) がこの符号の対称性を生んでいる。

### 話者ノート
「四元数は θ を [0,4π) で一周する (半角ゆえ実回転の二周ぶん)」。2π 回すと q = -1、4π でようやく q = +1 へ戻る ―― これがスピノルの二価性。深掘り希望時のみ触れる。

## ○ 外殻では対蹠へ跳ぶ
@ball VectorPart
@camera SpaceBall
@highlight WXYZ
@focus ballPose ballAntipode
@action flipSign

### 直感
回転空間 (外殻ボール) で見ると一目瞭然だ。q の点と -q の点は、原点をはさんで正反対 (中心対称) の位置にあり、色が反転 (暖色↔寒色) している。符号反転すると、点は対蹠へ跳ぶ。

### 数理
ベクトル部模型は p = sin(θ/2) n = (x,y,z) (spec §4.3)。v(-q) = -v(q) ゆえ中心対称。w の符号が色 (暖/寒) ゆえ、反転で色も裏返る。回転ベクトル模型では中心対称にならない (spec §4.3) から、この演出はベクトル部模型専用。

### 話者ノート
「なぜ既定がベクトル部模型か」の答えがここ。二重被覆が「点の中心対称」として一挙に見える。

## ◆ 姿勢の住処は S^3 ではなく RP^3
@camera SpaceBall
@highlight None
@focus ball

### 直感
q と -q が同じ姿勢なら、球面 S^3 の対蹠点どうしを同一視して貼り合わせなければならない。そうして現れる空間が RP^3 (実射影空間)。これが回転姿勢の真の住処だ。

### 数理
SO(3) ≅ S^3/{±1} = RP^3。二重被覆 S^3 → RP^3 は 2:1。外殻で軌跡が表面 (180°) に達したとき対蹠から現れるワープは、この貼り合わせの実体である (spec §4.3 ―― v1 で最も見せる価値のある演出)。

### 話者ノート
Ch.5 への伏線: 「この対蹠の貼り合わせを補間器が知らないと、遠回りが起きる」。二重被覆は美しいだけでなく、実害を生む (Ch.5 で回収)。
