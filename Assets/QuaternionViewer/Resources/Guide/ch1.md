## ◆ 4つの数の正体
@posture 1 2 0.5 120
@camera CoreAndGlobe
@highlight WXYZ
@demos None

### 直感
クォータニオンの4成分は、謎の4つの数ではない。回転軸 n (どの向きに) と回転角 θ (どれだけ) という、たった2つの情報を畳んだものだ。中殻を貫く地軸が n、これから読む角が θ。

### 数理
単位四元数は軸角表現 q = (cos(θ/2), sin(θ/2) n) を持つ (spec §2.4)。|n| = 1 ゆえ w^2 + |v|^2 = cos^2(θ/2) + sin^2(θ/2) = 1。4成分は独立ではなく、単位球 S^3 上の一点だ。半角 θ/2 の由来はビート4で暴く。

### 話者ノート
ここで「w は角、x,y,z は軸方向」と早合点させない。正しくは「w が角の余弦 (半角)、(x,y,z) が軸に半角の正弦を掛けたもの」。バーの動きで後述。

## ○ 軸を地軸として読む
@camera CoreAndGlobe
@highlight AxisAngle

### 直感
回転軸 n は、地球儀の地軸そのものだ。球面 S^2 上の緯度経度で、ただ一点に指せる。軸が球を貫く二点、北極 n と南極 -n を見よ。

### 数理
n ∈ S^2。これが「軸角表現の幾何学的写像」の実体だ (spec §4.2)。極は ±n を球半径倍した点。軸を S^2 の点として指せることが、中殻を「地球儀」と呼ぶ根拠であって、装飾ではない。

### 話者ノート
n と -n の両方が極になる点に注意を促す。「どちらが正の軸か」は回転の向き (spec §2.2 左ねじ) で決まる。

## ○ 角をゲージで読む・点を運ぶ
@camera CoreAndGlobe
@highlight AxisAngle

### 直感
二つの計器を分けて見る。地標ピンは「基準点 p0 が q でどこへ運ばれるか」= 作用を、軸周りの小円弧で描く。角度ゲージは「その角 θ はいくつか」= 計量を、常に最大の分度器で読む。

### 数理
ピンの掃く小円の半径は sin α (α = ∠(p0, n)) で、p0 ∥ n のとき 0 に退化する (spec §4.2)。ゆえに役割を分離する ―― ゲージは n 直交の大円上に取り、常に半径最大で θ を読ませる。既定 p0 は赤道上の (0,0,-1)、ゼロ基準は g0 = normalize(p0 - (p0・n)n)。

### 話者ノート
「ピンが縮んでもゲージは縮まない」を実演。軸を鉛直近くへ動かすと小円が痩せるが、ゲージは動じない ―― 作用と計量は別物という設計思想。

## ◆ 半角の核心: 二枚の鏡 (MIRRORS)
@demos Mirrors
@camera CoreAndGlobe
@highlight HalfAngle

### 直感
なぜ「半分」なのか。回転とは、二枚の鏡に像を映す操作だからだ。鏡が角 θ/2 で交わっていると、像は θ だけ回る ―― 鏡の間の角の2倍。この「2倍」の裏返しが、四元数に現れる「半角」の正体だ。

### 数理
平面鏡映は対合 v' = v - 2(v・m)m (spec §3.6-E)。法線が角 φ で交わる二枚 m1 → m2 の合成は、軸 m1×m2 周り・角 2φ の回転になる。ReflectionPair(n, θ) は φ = θ/2 を取り、合成作用が FromAxisAngle(n, θ) と一致する (EditMode 検証済み・spec §6.3-E)。バーで w = cos(θ/2)、|v| = sin(θ/2) を対比せよ ―― θ ではなく θ/2 の三角比が成分に立つ。

### 話者ノート
ここが Ch.1 の山。「四元数が半角なのは実装の都合ではなく、回転が二鏡映であることの必然」と締める。次章 (二重被覆) への布石: 半角ゆえ θ と θ+2π で符号が反転する。
