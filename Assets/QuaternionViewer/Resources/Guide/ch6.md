# Ch.6 角速度と微分方程式

> 台本の正典は docs/section-guide.md §4.6。本ファイルはその画面用転記 (SSOT は §4)。
> 儀の既定: 外殻=回転ベクトル模型 (測地線=放射直線が忠実、spec §4.3)。駆動は OmegaDriver (数値積分)。

## ◆ 姿勢の時間発展
@demos None
@camera Overview
@highlight WXYZ
@action normalizeOn
@action omegaWorld
@action omegaOn

### 直感
角速度 ω を与えると、姿勢 q が時々刻々と変わっていく。回転は「状態」であると同時に「運動」だ。その運動を支配する式がある。

### 数理
q' = (1/2) ω~_world ⊗ q (ワールド系) または q' = (1/2) q ⊗ ω~_body (ボディ系)、ω~ = (0, ω) (spec §3.3)。係数 1/2 は半角の分だけ (Ch.1)。積分器は RotationIntegrator (Euler法 / RK4)。

### 話者ノート
「1/2 はどこから?」に Ch.1 の半角で答えられる。章がここで円環する。

## ○ ワールド系 vs ボディ系
@camera Overview
@highlight WXYZ
@action omegaBody

### 直感
同じ ω でも、世界系 (外から見た固定軸まわり) とボディ系 (剛体に貼り付いた軸まわり) では、運動が全く違う。Unity の Space.World と Space.Self の違いそのものだ。

### 数理
世界系は左乗 ω~ ⊗ q、ボディ系は右乗 q ⊗ ω~ (spec §3.3)。四元数積の非可換性 (Ch.3) がここで運動の差として顕現する ―― 左から掛けるか右から掛けるかが、軸を世界に固定するか剛体に固定するかを決める。

### 話者ノート
このビートでボディ系へ切り替わる。前のビートと往復して運動の違いを見比べさせると効く ―― Ch.3 の非可換性が「実運動の違い」として効く実例。

## ◆ Slerp の正体は指数写像
@ball RotationVector
@camera SpaceBall
@highlight AxisAngle
@focus ball
@action clearTrail
@action omegaWorld
@action omegaOn

### 直感
ω を一定に保つと、姿勢は外殻 (回転ベクトル模型) の中を中心からまっすぐ、等速で進む放射直線を描く。これが測地線 ―― そして Slerp の正体だ。Ch.5 で「Slerp だけ角速度一定」だったのは、これだったのだ。

### 数理
ω 定数の厳密解は q(t) = exp((1/2) ω~ t) ⊗ q0 (spec §3.3)。Slerp は指数写像であり、角速度一定の測地線。回転ベクトル模型は半径が角に比例 (等尺) ゆえ、等角速度運動が中心からの放射直線として忠実に描かれる (ベクトル部模型では θ→π で表面へ圧縮され歪む ―― spec §4.3)。

### 話者ノート
Ch.5 ビート2「Slerp だけ一定」の回収であり、全章の理論的な収束点。軌跡が表面 (180°) に達すると対蹠へワープする ―― RP^3 (Ch.2) もここで再訪できる。

## ○ なぜ毎フレーム正規化が要るのか
@demos Graph
@camera Overview
@highlight QNormDrift
@action graphDrift
@action normalizeOff
@action omegaOn

### 直感
グラフ |q|-1 を見よ。数値積分を続けると、|q| が少しずつ 1 からずれていく。放っておくと q は単位球から落ちて姿勢が壊れる。だから毎フレーム正規化が要る。正規化を切ったいま、まさに発散が始まっている。

### 数理
q' = (1/2) ω~ q の厳密解はノルムを保つ (d/dt |q|^2 = 2<q, q'> = <q, ω~ q> = 0、ω~ が純虚ゆえ)。だが離散積分 (Euler法) は各ステップで接空間の方向へ一次で踏み出すため、S^3 の外へ漸進的に逸脱する。RK4 は高次項まで追って逸脱を抑えるがゼロにはできない。正規化は各ステップ後に q/|q| で S^3 へ射影する処置 ―― 理論 (ノルム保存) を離散化が破るから、射影で理論へ引き戻す。

### 話者ノート
「毎フレーム正規化は場当たりの呪文ではなく、多様体上の運動を接空間で近似することの必然的な補正」。Readout の |q|-1 行とグラフの両方が伸びていく。長く待つほど姿勢の壊れも見えてくる (サイコロの描画が歪む)。ここで全6章 ―― 軸角・二重被覆・非可換・座標特異点・補間・微分方程式 ―― が「q は S^3 (実は RP^3) 上に住む」という一点へ収斂する。章を離れれば次章頭の姿勢指示が駆動を止め、正規化はこの章の頭で戻る。
